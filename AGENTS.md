# QubNexa website

Single-package Next.js 16 App Router site (no monorepo, no tests, no CI). Code lives at the repo root — there is no `src/`.

## Commands

- Package manager is **npm** (only `package-lock.json` exists).
- `npm run dev` / `npm run build` / `npm run start`
- Verification (there is no typecheck or test script): `npm run lint` then `npx tsc --noEmit`

## Structure & conventions

- Path alias `@/*` resolves from the repo root (e.g. `@/app/layout`), per `tsconfig.json`.
- Tailwind v4 with no config file: theme tokens (`--color-background`, `--color-foreground`, Geist font vars from `next/font`) are defined via `@theme inline` in `app/globals.css`. Dark mode follows `prefers-color-scheme` via a media query — there is no class-based toggle.
- Animation/3D libraries are already installed but unused so far: framer-motion, gsap, lenis, three, @react-three/fiber, @react-three/drei, lucide-react. Use them instead of adding new deps.
